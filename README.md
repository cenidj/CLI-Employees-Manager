# Employee Management System

A Python application for managing employees, ages, their departments, and salaries.

## Features

- Display employees
- Search employees
- Add employees
- Delete employees
- Filter by department
- Filter by salary
- Calculate average salary
- Find the highest-paid employee
- Error handling
- Data persistence
- Logging

## Technologies

- Python
- JSON
- Git
- GitHub
